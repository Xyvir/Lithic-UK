Lithic is a personal knowledge base for people who want their notes to outlast the app. Your wiki is a single `.lith` file on a disk you choose, or on a server you run. Nothing requires an account, a subscription or a connection.

A `.lith` is a plain-text file that holds many notes together, a bit like several Markdown files joined together into one. Each note keeps its own title and tags, and the whole file opens in Lithic on any device. Because it is text, you can read it, copy it, diff it, or hand it to an AI tool.

## Why Lithic

* **Your notes are a file you own.** Keep them on your laptop, a USB stick or your own server. Move them by copying the file.
* **Free and open source, forever.** There is no paid tier and no plan to add one.
* **Works offline.** The whole app is one file. It runs from a USB stick, over `file://`, or on a machine that has never been online.
* **Ready for AI to read.** The `.lith` format was designed to be ingested by AI. The Copy Story River button copies your current notes in one block, ready to paste into a chat-based AI tool. Lithic has no direct AI integration, and it will not add one.
* **Built on TiddlyWiki.** It runs on the TiddlyWiki engine and its plugin ecosystem, with a launcher, plugins and desktop builds added on top.

## Where It Runs

* **Browser:** open [lithic.uk](https://lithic.uk) or install it to your Home Screen on an iPhone or iPad.
* **Desktop:** Windows, Linux and macOS builds, with optional GitHub backup of your folder.
* **Android:** a single APK.
* **Self-hosted:** run it on your own server with Docker, LXC or Railway.
